# @miasaki/dsh-appearance — 外观

> DSH（DeepSeek Harness）插件：在「设置」里新增一栏 **外观**，
> 集中管理**主题皮肤 / 壁纸 / 动效 / 会话效果**。

三条硬约定：

- **零 shell 改动** —— 只用官方扩展点（`settings.section` 插槽 + `ctx.theme` 服务 + `webserver/index-inject` 首帧注入），
  不修改 DSH 本体、不注入压缩 bundle；
- **零第三方依赖** —— host 半只用 Node 内建模块，配置自管 JSON；
- **关掉即原生** —— 总开关默认**关闭**，未配置时对页面**可见像素零影响**。
  实现口径：首帧**无条件**写 4 个门控属性（`data-mia-appearance` / `-skin` / `-glass` / `-wallpaper`），
  关闭时取值为 `off` / `pure` —— 属性在场但**本线之外无消费者**，故渲染结果与原生一致。
  （2026-09-29 订正：此前本行写「只写两个」，与实现的 4 个不符。）这是本插件的硬契约与验收项。

## 能调什么

### 皮肤

两套完整配色（**刻刻帝** / **狂狂帝**），各自是一张 **105 个 token** 的编译表（由脚本从源码主题派生，产物可校验）：

- **首帧防闪色**：皮肤在页面首帧就注入，不会先闪一下原生配色再变色；
- 覆盖的是 DSH 的 `--dsw-static-*` 色阶与品牌 alias，**不动布局**，所以 DSH 升级不会错位。

### 壁纸与玻璃

- **图源**：内置程序化渐变（不需要任何图片文件）/ 本地目录图源 / 我的上传；
- **玻璃四档**：`off` / `mica` / `light` / `frost` —— `mica` 档在 Win11 桌面壳下走系统云母；
- **表面不透明度四旋钮**：分别控制页面 / 面板 / 浮层 / 卡片，走 `color-mix`，
  **自动跟随皮肤、自动跟随明暗**；
- 壁纸铺排带 scrim 与 vignette 两层，保证文字在任何图上都可读。

### 动效

- 三档预设 + **强度倍率**；
- 纯 CSS 变量驱动，只动 `transform` / `opacity`（零布局属性、零 JS 循环）；
- 作用面：侧栏 / 会话表面 / 右栏的加载入场，以及**打开设置时整块面板入场一次**
  （页签之间切换一律瞬切，与官方设置外壳一致——动效不按页签分叉）；
- **全局尊重 `prefers-reduced-motion`**（系统开了减弱动效就全静止，功能不变）；
- **Boot Splash**：首帧全屏启动画（三主题纹章动效），退场双信号 + 2.5s 超时兜底，
  **绝不挡住错误页**。

### 会话效果（M4）

消息密度 / 会话宽度 / 正文字体 / 流式光标 / 光标样式 / 引用与代码块 ——
首档即「原生」（不注入任何规则），关掉即完全回到原样。

### 软件头像

上传一张 PNG 作为头像。桌面壳 `Miasaki.exe` 读**同一份配置**，把它用作窗口 / 任务栏 / 托盘图标；
另内置三款可直接选的预设（默认 / 头像 / 立绘）。

## 安装

```bash
# 尚未发布到 npm —— 发布后：
dsh plugin --profile <profile> add @miasaki/dsh-appearance
```

装完**重启 DSH**并刷新页面，设置里出现「外观」一栏。

**要求 DSH 0.1.7 及以上。**

## 与官方「通用」设置页的边界

**官方「通用」页里已有的，这里不做第二入口**：

| 项 | 归属 |
|---|---|
| 明暗偏好（浅色 / 深色 / 跟随系统） | 官方「通用」页 |
| 正文字号 | 官方「通用」页 |
| **皮肤**（官方三立方没有的） | 本插件 |
| 壁纸 / 玻璃 / 动效 / 会话效果 | 本插件 |

控件形态也跟官方对齐：单选走**官方选择丸 + 下拉菜单**，卡片走官方圆角与分隔线规格，
不引入自制控件语言。

## 配置

配置自管 `~/.dsh/miasaki-appearance/config.json`（当前 **v6**，旧版本载入时自动迁移）。

- 写盘失败会**如实失败**（`500 + changed:false` + 可读原因），不假报成功；
- 原子写（临时名带 pid / 时间戳），避免多实例互踩半截 JSON；
- 面板显示的是真实修订号，不会拿陈旧值骗你。
