# Miasaki Desktop — 主题与桌面端设计规范

- 版本：v0.1
- 日期：2026-08-16
- 状态：实现蓝本（唯一依据）
- 作者：Miasaki 会话

> 本规范定义「Miasaki 专属 DSH 桌面端」的架构与三主题原创设计。
> 角色灵感参考《约会大作战》时崎狂三（刻刻帝/狂狂帝），设计全部原创，不复制任何第三方工程资产。

---

## 1. 架构

### 1.1 形态

Tauri 2 薄壳（Rust + WebView2），不改造 DSH 本体：

```
Miasaki Desktop（EXE，双击即开）
 ├─ 启动器（Rust）：单实例锁 → 探活 127.0.0.1:3080
 │    ├─ 未运行 → 后台拉起 `dsh web`（无窗口、日志落盘）→ 轮询端口就绪
 │    └─ 就绪 → 窗口从本地 loading 页导航到 http://127.0.0.1:3080
 ├─ 窗口：1280×800（最小 960×600），标题「Miasaki · DSH」，关闭即退出（DSH 服务保持运行）
 └─ 主题引擎：初始化脚本注入远程页面（无 IPC、无 CSP 障碍）
      ├─ 声明 `html[data-miasaki-theme]` + 控制 `body[data-ds-dark-theme]`
      ├─ 覆盖 DSH 令牌层（--dsw-static-* 色阶 + 少量 --dsh-* 杂项）
      └─ 悬浮主题切换条 + 本地持久化（localStorage）
```

### 1.2 DSH 令牌体系（调研结论）

- DSH Web GUI 无 CSP 头 → 注入样式/脚本不受内容安全策略限制。
- 全部颜色经两层令牌：`--dsw-static-*`（色阶，共 73 个）→ `--dsw-alias-*`（语义别名）→ 组件。
- 明暗模式 = `<body>` 上的 `data-ds-dark-theme` 属性（内联 bootstrap 按 localStorage 偏好 + `prefers-color-scheme` 决定，并写 `color-scheme`）。
- **结论：主题 = 重定义静态色阶。** 别名层保持原语义（层次、状态、边框透明度），只换色阶取值。

### 1.3 注入与优先级

主题块选择器采用 html + body 双目标，特异性 (0,2,x) 恒高于 DSH 的 `:root`(0,1,0) 与 `[data-ds-dark-theme]`(0,1,0)：

```css
html[data-miasaki-theme="zafkiel"],
html[data-miasaki-theme="zafkiel"] body { /* 令牌重定义 */ }
```

- 注入时序：document 创建即挂属性（防闪烁）→ `DOMContentLoaded` 时按主题**锁定** `body[data-ds-dark-theme]`（zafkiel 强制开 / kurkuriel 强制关 / pure 不干预）→ MutationObserver 持续再断言（用户在 DSH 设置里改明暗也不破坏主题）。
- 切换主题 = 改 `html[data-miasaki-theme]` 属性 + 交换样式块内容；持久化到该源的 localStorage。
- 调试钩子：URL 参数 `?miasaki-theme=zafkiel|kurkuriel|pure` 可强制当次主题（便于分享与验证）；Rust 侧 `MIASAKI_REMOTE` 环境变量可覆盖导航目标地址。
- 构建期由 `scripts/build-init.mjs` 把 `themes/*.css` 内联进运行时脚本，产出 `src-tauri/injected/theme-init.js`，Rust 以 `include_str!` 注入——**发布包零网络请求**。
- 构建脚本同时做**令牌完备性校验**：从 `design/token-surface.txt` 提取的全部 `--dsw-static-*` 引用必须被每个非 pure 主题覆盖，缺失即构建失败。

### 1.4 主题切换条

- 形态：窗口右下角悬浮圆形按钮（默认收起），悬停展开三枚主题卡。
- 结构：仅由注入层创建（DOM + 样式均归主题运行时所有，不依赖 DSH DOM）。
- 视觉：随主题换肤；pure 下为中性灰。z 轴最高（99990），不遮挡对话输入区关键操作（v1 固定在右下角，位于输入框旁安全区）。
- 切换动效：全屏 400ms 过渡遮罩（zafkiel→金红表针扫过；kurkuriel→血红破碎横切；pure→淡入淡出），随后落定新主题。

## 2. 主题设计

### 2.0 pure — 原版简约纯净

> 定义：**不注入任何颜色覆盖**，DSH 原生样貌完整透传；仅保留悬浮切换条（中性灰样式）。

- `html[data-miasaki-theme="pure"]` 不声明任何令牌；`body[data-ds-dark-theme]` 交还 DSH 自己管理。
- 兜底语义：任何主题异常时运行时自动回落 pure，保证 GUI 永远可用。

### 2.1 zafkiel — 刻刻帝「永夜钟阁」

> 气质：优雅、危险、古典钟阁。暗夜基底 + 右瞳绯红（交互）+ 左瞳鎏金（装饰），金红分职不混用。

**色板（原创取值）**

| 令牌组 | 取值 | 语义 |
|---|---|---|
| `neutral-bluish-950` | `#0B0A10` | 页面基底·墨夜 |
| `875 / 850 / 800` | `#131019` / `#181420` / `#1E1928` | 面板三层层进 |
| `750 / 700` | `#262031` / `#2F283C` | 浮层/悬停 |
| `600 / 500 / 400` | `#4A4157` / `#5D5369` / `#7A6F85` | 边框·次级文字 |
| `300 / 200 / 150 / 100` | `#9A8FA8` / `#B8AEC4` / `#D2C9DC` / `#E4DEF0` | 文字层级 |
| `50 / 00` | `#F2EDF8` / `#FAF7FC` | 前景·高亮·按钮字 |
| `deepseek-*`（品牌→钟刻绯红） | `450:#C23A2E` `500:#B3362C` `400:#D44A3C` `300:#E0B0A8` `200:#EBD0CC` `100:#F2DFDC` `50:#F7EBE9` `600:#9A2F26` `800:#5A2B28` `900:#3A2122` | 按钮·链接·焦点环·选中 |
| `red-*`（语义错误） | 400 `#E06A5C` / 600 `#C4493A` | 与绯红同源、降饱和 |
| `amber-*`（语义警告） | 400 `#D9B36A` / 500 `#C9A25A` / 600 `#A98944` | 鎏金同源 |
| `green-*`（语义成功） | 400 `#6FA77C` / 500 `#55895F` | 低饱和苔绿 |
| `blue-*`（信息/引用） | 400 `#7D96C9` / 500 `#61799F` | 灰蓝，克制 |

**形态语言**
- 圆角：卡片 8px / 控件 6px / 浮层 12px（跟随 DSH 原几何，不改变布局，只换色与装饰）。
- 装饰（注入层专属，不动 DSH 组件结构）：
  - 背景右下角半透明**表盘水印**（原创 SVG：罗马数字环 + 12 刻度 + 齿轮剪影，透明度 6%）；
  - 滚动条：鎏金暗纹 thumb，hover 提亮；
  - 文本选择 `::selection`：绯红底月白字；
  - 焦点环：绯红外发光（2px）；
  - 文本输入光标：**金色表针**（`caret-color` 鎏金实现，兼容性最稳）；
  - `h1/h2/h3` 标题点缀衬线字族（Palatino 优先），正文保持系统无衬线。
- 动效：hover/选中 200ms；流式等待态沿用 DSH 自身动画，仅重着色。

**文案与细节**
- 切换条选项名：`原版` / `刻刻帝` / `狂狂帝`；悬停提示：「ふふふ，今晚的时间也属于我呢」。
- 切换过渡：金色表针顺时针扫过全屏 360ms。

### 2.2 kurkuriel — 狂狂帝「白夜逆钟」

> 气质：反转、支配、破碎。骨白基底（与刻刻帝互为反转）+ 血绯（交互）+ 枪铁（身份装饰，替代鎏金）。
> 十二星座取代罗马数字成为装饰母题（♌ ♏ ♒），短句命令式文案。

**色板（原创取值）**

| 令牌组 | 取值 | 语义 |
|---|---|---|
| `neutral-bluish-950`（→ 页面基底） | `#E9E5E1` | 骨白 |
| `875 / 850 / 800` | `#F2EFEB` / `#F8F5F2` / `#FFFFFF` | 面板三层层进 |
| `750 / 700` | `#E2DDD8` / `#D8D2CC` | 浮层/悬停 |
| `600 / 500 / 400` | `#B3AAA2` / `#948A81` / `#7A7168` | 边框·次级文字 |
| `300 / 200 / 150 / 100` | `#5F564E` / `#4A423B` / `#3B342E` / `#2E2924` | 文字层级 |
| `50 / 00` | `#241F22` / `#171315` | 前景·标题 |
| `deepseek-*`（品牌→血绯） | `450:#9E1B1B` `500:#8F1616` `400:#B52525` `300:#E0A9A9` `200:#ECD0D0` `100:#F2DCDD` `50:#F7E9EA` `600:#7A1212` `800:#4E2020` `900:#33191A` | 按钮·链接·焦点·选中 |
| `red-*` | 与血绯同源 | 语义错误 |
| `amber-*` | 降饱和沙金 `#B89A5C` 系 | 语义警告 |
| `green-*` | 低饱和苔绿 | 语义成功 |
| `blue-*` | 枪铁蓝灰 `#5E6572` 系 | 信息/引用 |

**形态语言**
- 质感反转：亮面为主、阴影更硬（黑 12%）；边框偏枪铁色。
- 装饰：
  - 背景左上角**破裂表盘水印**（原创 SVG：断裂刻度环 + 裂纹，透明度 7%）；
  - 选中/焦点：血绯 + 轻微红色故障辉光（`box-shadow` 双层，hover 时 120ms 内闪现一次 glitch 位移）；
  - 滚动条：枪铁 thumb；
  - 文本输入光标：**绯红碎片**（`caret-color` 血绯实现）；
  - 角落星座字符点缀（注入层绝对定位，透明度 5%，♌♏♒ 三枚）；
  - `h1/h2/h3` 使用窄体黑（Arial Narrow 优先）营造锋利感。
- 动效：常规过渡 160ms（比刻刻帝更短促）；切换过渡 = 血红横切 + 破碎颗粒 400ms。

**文案与细节**
- 切换条悬停提示：「选好了吗？我讨厌犹豫的人」。
- 空态/加载页文案（桌面端本地页）：「Zafkiel 反转中——」等命令式短语。

### 2.3 通用规则

- 语义色永不被角色色替换：成功=绿系、警告=金/沙系、错误=红系，只做降饱和适配。
- 装饰层（水印、角饰、光标、切换条）是唯一允许的角色视觉发挥区；DSH 组件几何与布局零改动。
- 三主题都保持 WCAG 对比底线：正文 ≥ 4.5:1，装饰元素不承载信息。
- 尊重系统 `prefers-reduced-motion`：全部过渡动画降级为淡入淡出。

## 3. 启动器与窗口规范

- 单实例：二次启动唤起已有窗口（`tauri-plugin-single-instance`）。
- 探活：每 400ms 尝试 TCP 连接 `127.0.0.1:3080`，上限 30s。
- 拉起：`cmd /C dsh web`，`CREATE_NO_WINDOW`，日志追加到 `%LOCALAPPDATA%\miasaki\server.log`；进程不被应用退出带走（服务常驻）。
- 失败路径：loading 页显示「未能唤醒 DSH —— dsh 命令不可用或服务启动失败」+ 重试按钮（重试=重新探活+拉起）。
- loading 页为本地静态页（tauri://localhost），深色中性、显示 Miasaki 纹章与唤醒状态文案；就绪后导航远程页。
- 应用标识：`com.miasaki.desktop`，产品名 `Miasaki`，窗口标题 `Miasaki · DSH`。
- **发布形态**：`cargo build --release` 直接产出便携 EXE（`src-tauri/target/release/miasaki.exe`，WebView2 已内置于系统）；NSIS 安装包需 tauri CLI 联网下载打包器，暂不作为默认形态。

## 4. 目录结构（desktop/）

```
desktop/
├─ package.json                 # @tauri-apps/cli + build-init 脚本
├─ ui/loading.html              # 本地唤醒页（静态）
├─ themes/                      # 主题源文件（原创，无第三方资产）
│  ├─ pure.css
│  ├─ zafkiel.css
│  ├─ kurkuriel.css
│  └─ runtime.js                # 注入运行时：属性管理/切换条/过渡/持久化
├─ scripts/build-init.mjs       # 内联打包 + 令牌完备性校验
└─ src-tauri/
   ├─ Cargo.toml / build.rs / tauri.conf.json
   ├─ capabilities/default.json
   ├─ injected/theme-init.js    # 构建产物（include_str! 注入）
   └─ src/main.rs               # 启动器 + 探活 + 导航
```

## 5. 验收标准（v1）

1. 双击 EXE：未启动 DSH 时自动拉起并打开 GUI；已启动时直接打开。
2. 悬浮条可切换三主题，重启应用后记忆保持。
3. zafkiel / kurkuriel 下 DSH 全界面（对话、工具卡、侧栏、弹窗、代码块）无原蓝色残留。
4. pure 下 DSH 外观与直接访问 127.0.0.1:3080 完全一致。
5. 关闭窗口，DSH 服务仍在运行（再次双击秒开）。
6. 令牌完备性校验通过（build 脚本强制）。
