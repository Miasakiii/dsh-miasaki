# @miasaki/dsh-free-model — 免费模型聚合器

> DSH（DeepSeek Harness）插件：把**本机的免费模型收在一处** ——
> 同一张模型卡、同一套能力画像，还能一键设为默认。

免费模型在这台机器上有两个来源，本插件把它们放进同一个视图：

| 来源 | 是什么 | 怎么取数 |
|---|---|---|
| **① 免 Key 车道** | 装完即用、**不需要任何 Key** 的 provider 路由 | **官方 `llm` 契约**：`listProviders` → `listModels` → `resolveModelInfo` |
| **② 本机自配平台** | `llm-pi-ai.providers` 里带 `baseURL` 的任意 OpenAI 兼容平台（OpenRouter、自建网关…） | 直连该平台 `GET {baseURL}/models` |

来源 ① 走官方契约的意味：**只读、零改动、零配合** —— 对方只需作为 DSH provider 存在，
本插件不读它的私有路由、不读它的存储、不改变它的任何承诺。

## 模型卡上有什么

- **免费判定与依据**：命中哪条规则（provider 级免 Key 车道 / `:free` 后缀 / 定价全零 / 名称含"免费"）会明确标出；
- **能力画像**：工具调用、`tool_choice`、视觉、推理、编码、长上下文、**子代理可用性**；
- **决策摘要**：按你的用途给出「这批里哪个更合适」。

**能力只到能被证明的程度**：适配器没声明工具参数，就标「未声明 · 需实测」——**不猜 `false`**。
宁可让你去测，也不给一个看着确定、实则编造的结论。

## 能做的动作

| 动作 | 说明 |
|---|---|
| **实测** | 接 `dsh-model-probe` 的两段式真实探测（那个可选插件缺席时整块按钮隐藏，不装作能测） |
| **设为默认** | 走**官方** `agentDefaultModel.saveSelection`，下一次会话立即生效 |

## 安装

```bash
# 尚未发布到 npm —— 发布后：
dsh plugin --profile <profile> add @miasaki/dsh-free-model
```

装完**重启 DSH**并刷新页面。

**要求 DSH 0.1.7 及以上**（依赖 `settings` 与 `webServer` 两个官方服务）。

### 界面挂在哪

设置里那一栏「**免费模型**」就是上游插件 `dsh-our-free-model` 的设置页本身 ——
本插件用[增量补丁](patches/dsh-our-free-model/)在它里面做加法（去掉公告分区与首启弹窗、
左栏改名、模型清单后挂上「本机自配平台」、**分区标题提档到 16px** —— 上游的 14px 与卡片名
13.5px 几乎同级，分区与内容看不出层级），并把它的**弹窗公告静默化**。

- 上游在场：**让位**，保证只有一个入口；
- 上游不在场：本插件注册自己的设置页顶上。

### 不再弹窗，更新在设置页说

上游原本会主动弹三处右下角弹窗（新公告 / 「插件可升级」/ 热重载提示），
紧急公告还会开全屏模态、并可能发系统通知。补丁**把这三条通道全部关掉**：

- 公告：不再有任何弹窗（公告中心分区此前已删，公告彻底静默）；
- **更新**：有新版本时，在「免费模型」页**顶部**（hero 之后）出现一条提醒条，
  写清 `当前 → 最新`，带「立即升级」「稍后再说」；没有新版本时**不占位**；
- 热重载：不再提示。

「立即升级」与下方「升级」分区的按钮**都走同一个 240 秒超时的请求**：上游 `api()` 给每个请求
套了 8 秒 `AbortController`，而一次自升级要「拉 manifest（15s）→ 并发下载全部文件（每路 30s）→
安装 → 热重载」—— 8 秒必然打断，**真实失败原因随 500 到达时客户端早就走了**
（2026-10-07 实测：用户只看到 `signal is aborted without reason`，而 host 侧其实记着
`staging failed: … fetch failed`）。现在失败原因会照实显示在提醒条里。

唯一保留的弹窗是设置页里「保存失败」的即时应答 —— 那是对你刚做动作的回话，不是公告。

> 补丁按**锚点**改写本机安装副本，可重放 / 可自检 / 可回退。上游自升级后重打即可
> （`node patches/dsh-our-free-model/patch.mjs`）。
> **升级前先预判**：2.0.0 实测 12 处锚点只有 8 处还能命中（3 处 drift ⇒ 重打会显式失败）——
> 命令与判据局限见[补丁 README](patches/dsh-our-free-model/README.md) 的「升级前先预判」一节。

## 安全

本插件的 HTTP 路由（`/freemodel-api/*`）**全部过信任围栏**：

- 优先读 DSH 内核的 `connection.requestRejection`（逐请求读取，不缓存）；
- 该服务缺席时按结构层复刻（回环 Host / 拒绝跨站 `sec-fetch-site` / Origin 与 Host 同名）；
- **围栏先于 method 检查** —— 跨站请求得到 403 而不是 405，不泄露接口形状。

这条围栏是必要的：`/apply` 是**写配置**的动作，`/subagent` 会改预设文件 ——
它们此前是裸奔的。

## 边界

- 只读官方契约，**不改第三方插件的任何行为**；
- 不注册 `settings.models.*` 槽位 —— 官方模型页的编辑面板也 dispatch 那个槽，
  occupant 一出问题就整树白屏（这是用一次事故换来的纪律）；
- 不直接调模型。
