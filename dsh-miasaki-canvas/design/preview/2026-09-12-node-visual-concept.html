03令牌对照

全部取值集中为令牌，替换现有约 30~40 处裸值。下表中的每一项都不涉及数据层。

令牌现值提案说明
--node-radius7px16px卡片；内层按钮 8px，构成两档结构
--node-shadow-rest0 3px 11px .080 1px 2px .04 + 0 6px 16px .06静置：更轻、更"浮"
--node-shadow-hover0 8px 20px .130 2px 4px .05 + 0 12px 28px .10悬停
--node-shadow-drag（无）0 4px 8px .06 + 0 20px 44px .16新增：拖动/选中态
--canvas-border#d8e0e8（裸值）#d8e0e8 / 暗 #2c3138提为令牌，供混色使用
卡片边框固定灰color-mix(--thread-color 14%, --canvas-border)让每条线带自己的身份色
--edge-width1.5px2px（活动 2.5px）圆线帽；活动路径靠粗细+颜色双通道
--edge-color#aebbc9#c3cdd9降对比，退到卡片之后
端点无6px 圆，opacity .35 → hover .8把"线"变成"连接"
标题13px / 72014px / 600字重需实机确认（见下方注记）
meta10px11px10px 低于可读下限
正文12px / 1.5812.5px / 1.65310px 宽卡上更透气
--motion-fast / base140 / 150 / 180ms 混用150ms / 180ms统一节奏；仅 transform / opacity
待实机确认。 字重 720 → 600 的前提是字体支持可变字重。若 DSH 主题字体在 Windows 上回退到非可变字体，浏览器会取最近档 700，此时 720 与 700 等价，改为 600 会变细。建议先对三主题（pure / zafkiel / kurkuriel）各截一张对比图再定；若偏细则回落 650。此项不阻塞其余改动。

04四阶段计划

每阶段独立可验收；任一步中止都不产生半成品。全部为表现层改动。

V1

令牌化与圆润化

建立令牌组，应用圆角 / 阴影 / 边框 / 字阶 / 间距。纯 CSS，零 DOM 变更。

styles.css
V2

连线语义与端点

2px 圆头、活动线加粗、端点圆点、按缩放的内容分级（LOD）。connectorPath 算法保持不变。

styles.css · app.js（conversationCard 增加端点 span）
V3

状态徽标与信息层次

统一徽标体系；合并草稿的 draft / pending / committed / failed 与失效态表达为卡头状态带。

styles.css · app.js
V4

收口与动效统一

小地图 / 多选条 / 手势气泡 / 检查器 / 空状态统一到令牌；动效收敛到 150ms 并尊重减少动效偏好。

styles.css
概念稿 · 静态对照，未接入真实数据。真实观感受主题令牌（--canvas-accent 派生链）、字体回退与缩放档位影响，实施后需以实机截图为准。
