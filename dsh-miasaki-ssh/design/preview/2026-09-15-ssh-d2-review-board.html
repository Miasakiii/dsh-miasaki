03异常与处置记录

  • 探针桩 slots.inject 语义缺陷（dispose+重 apply 后 find() 拿到旧代闭包，launcher 点击操作了已出 DOM 的宿主）：处置 = 桩改为 cordis 同名替换语义；非产品缺陷。
  • 单测桩缺属性选择器 / click()：D2 契约需要 [aria-label="…"] 查询与程序化点击；处置 = 桩 matches 取选择器末段匹配 + 节点补 click()。
  • 临时清理被安全护栏拦截（.openclaw/tmp 探针目录删除）：处置 = 不重试，目录在 ignore 区无害，有效探针已归档 _refs。

04风险与回滚

  • 消息防伪：overlayToken 随机、仅经 chrome 消息下发、宿主严格校验（单测覆盖错 token 拒绝）。
  • 回滚入口：git revert 本批 commit → 临时退出条版本（D1 热修形态），功能可用；更彻底回 view-only 需 revert D1 批次。
  • 遗留：实机三主题观感与桌面壳窗控让位的视觉复验（需重启 dsh web，用户动作）。
