# @miasaki/dsh-ssh — 页面内 SSH

> DSH（DeepSeek Harness）插件：**不用切外部终端**，在会话里直接连服务器跑命令、传文件。

入口在**会话头第一行的三段胶囊**里（与「对话 / 会话布」同一个控件，第三段是 SSH）；
画布页面内部那组按钮旁也有一个 SSH，走画布的外部视图槽。

## 能力

### 交互式终端

- **多 shell**：同一连接下可开多条独立 shell，各自独立的回放环与尺寸；
- **工作区记忆**：记住每个连接上次用的 shell 与序号，重连精确恢复；
- **会话自愈**：SFTP 传输层死亡自动重开一次，再失败原样上抛（不静默吞）；
- **背压保护**：慢 viewer 到高水位先 `pause` 而不是断开，全 drain 后 `resume`。

### 文件传输（SFTP）

右抽屉里的文件面板：浏览 / 上传 / 下载 / 新建目录 / 重命名 / 删除。

上传走**降级链**：SFTP 主路失败（目录在 sftp 视图不存在、会话打不开）时，
**零字节消耗**直降 `mkdir -p && cat >` 命令通道；mid-stream 失败则记 `execOnlyUpload`，下次直走命令通道。

### 跳板与转发

- **跳板（ProxyJump）**：经已连接的跳板机开通道；
- **本地端口转发**：把远端服务映射到本机端口；
- 端口被占、服务端拒绝都如实报错（**静默不生效比报错更糟**）。

### 连接管理

- **`~/.ssh/config` 导入**：`ssh -G` 优先 + 自研解析回退，只导直连 alias
  （含 ProxyJump 的禁选，但**不静默丢**）；
- **主机指纹（TOFU）**：首次连接要你确认指纹；**指纹变化一律拒绝且绝不静默更新**；
- **票据一次性**：WebSocket 升级用一次性票据，teardown 即作废；
- **口令不进记录**：连接记录里永远不存密码。

## 让 Agent 也能用 SSH（可选）

默认**关闭**。在插件配置里打开 `agentTools` 后，模型获得三个工具：

| 工具 | 作用 |
|---|---|
| `ssh_hosts` | 列出可用的主机（只列 `agentAccess ≠ none` 的） |
| `ssh_exec` | 在主机上执行命令 |
| `ssh_session_read` | 只读当前 shell 的回放尾部 |

**访问控制是分层的**：

- 每台主机设 `none` / `readonly` / `full` 三档；
- 命令按风险分级 —— **L0 只读免审批**、L1 变更需审批、L2 危险（`rm -rf` / 重启类）
  在 `readonly` 档**连审批机会都没有**；
- 审批走官方 questions 通道；**确认通道不可用时失败关闭**（不执行），不静默放行；
- **审计台账只记命令与决策，不落任何输出内容**。

## 安装

```bash
# 尚未发布到 npm —— 发布后：
dsh plugin --profile <profile> add @miasaki/dsh-ssh
```

装完**重启 DSH**并刷新页面，会话头三段胶囊里出现 SSH。

**要求 DSH 0.1.7 及以上。**

> 依赖 `ssh2` 与 `@xterm/*`（随包声明）。Agent 工具面需要 DSH 的 `agentTools` 服务在场，缺席时只告警不报错。

## 红线

- 不改系统提示、不改模型请求、不改工具 schema；
- DSH 原生会话是唯一事实来源；插件不直接调模型；
- 密码不落盘、输出不入台账、指纹变化不自动接受。
